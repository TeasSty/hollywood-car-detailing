# HOLLYWOOD CAR DETAILING

Промосайт детейлинг-центра в Ярославле. Статический сайт на Astro без UI-фреймворков, с авторским CSS и конструктором заявки в WhatsApp.

Публичный адрес: <https://teassty.github.io/hollywood-car-detailing/>

## Визуальная система

Оформление построено на фирменном стиле сообщества студии во ВКонтакте
(<https://vk.com/hollywoodcardetailing>): ретро-голливудская ключевая графика с обложки,
неоновая маджента из логотипа и плакатная типографика.

| Роль            | Значение                                                    |
| --------------- | ----------------------------------------------------------- |
| Фон             | `#0A0A0C` (основной), `#131318` (секции), `#1E1E25` (блоки) |
| Текст           | `#F6F4F1`, приглушённый `#9C9CAA`                           |
| Акцент          | `#FF2F92` — единственный акцентный тон, взят из логотипа    |
| Заголовки       | Oswald Variable                                             |
| Скрипт логотипа | Yellowtail (только латиница в лого-локапе)                  |
| Текст           | Manrope Variable                                            |

Шрифты подключены локально через Fontsource, внешних CDN нет.

## Структура

```
public/            favicon, manifest, robots.txt, sitemap.xml, og-cover.jpg
src/assets/        ключевая графика и фотографии работ (оптимизируются Astro в WebP)
src/components/    Wordmark.astro — лого-локап HOLLYWOOD + неоновый скрипт
src/pages/         index.astro — единственная страница
src/styles/        global.css — вся визуальная система
```

## Содержание страницы

- плакатный первый экран и полноширинная полоса с фирменной графикой студии;
- неоновая бегущая строка с направлениями работ (останавливается при `prefers-reduced-motion`);
- девять направлений работ без цен и выдуманных пакетов;
- галерея реальных кадров из официального профиля студии;
- конструктор заявки: отметки работ и детали собираются в готовое сообщение,
  которое пользователь сам отправляет в WhatsApp — данные не покидают браузер;
- контакты, доступные без JavaScript.

## Локальный запуск

```bash
npm ci
npm run dev
```

Сборка с проверкой типов:

```bash
npm run build
```

Проверка форматирования:

```bash
npm run format:check
```

## Публикация

Workflow `.github/workflows/deploy.yml` собирает ветку `main` и публикует каталог `dist`
через GitHub Pages Actions. `base` в `astro.config.mjs` — `/hollywood-car-detailing`,
все внутренние ссылки строятся через `import.meta.env.BASE_URL`.

## Примечания

- Цены не публикуются: актуальный прайс появится после согласования с клиентом.
- Реквизиты ИП на сайте не размещаются.
- Telegram не подключён: публичной ссылки вида `t.me/username` не подтверждено.
- Фотографии работ взяты из официального профиля студии; сторонние стоковые кадры не используются.
- Форма ничего не отправляет на сервер — она только формирует текст сообщения для WhatsApp.
- Адрес требует сверки: в описании сообщества ВКонтакте и на карточке студии указан
  Ленинградский проспект, 123 / 123Д. На сайте оставлен адрес, подтверждённый клиентом.
