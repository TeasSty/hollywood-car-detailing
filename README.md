## Signature Viewer

Секция «Детейлинг — полный уход» (`#signature`):

- **Wireframe SVG:** белый line-art седана (¾ вид спереди), не фото и не 3D.
- **Золотые callout-линии:** точки на зонах кузова → подписи услуг с реальными ценами; hover/click/focus подсвечивает линию и лейбл, остальные приглушает.
- **Прайс** (`#prices`) под схемой синхронизируется с зонами.
- `prefers-reduced-motion`: без stroke-draw и пульсации точек.

Ранее в переписке фигурировал адрес «Полушкина Роща, 123». Он **не** совпадает с публичной карточкой студии, поэтому на сайте стоит адрес из официальных источников. Если нужен другой — напишите.
