# HOLLYWOOD CAR DETAILING

Промосайт детейлинг-центра в Ярославле. Статический сайт на Astro с интерактивом «Осмотр 123»: посетитель отмечает задачи, указывает автомобиль и удобный день, после чего открывает WhatsApp с подготовленным сообщением.

## Содержание

- авторская адаптивная визуальная система «Ночная приёмка»;
- услуги без неподтверждённых цен и пакетов;
- текстовый журнал подтверждённых автомобилей без стоковых фотографий;
- доступный интерактив с клавиатурным управлением;
- контакты доступны без JavaScript;
- canonical, Open Graph, Twitter Card, JSON-LD, manifest, sitemap и robots.txt;
- автоматическая публикация на GitHub Pages.

## Локальный запуск

```bash
npm ci
npm run dev
```

Сборка и проверка типов:

```bash
npm run build
```

Проверка форматирования:

```bash
npm run format:check
```

## Публикация

Workflow `.github/workflows/deploy.yml` собирает ветку `main` и публикует каталог `dist` через GitHub Pages Actions.

Публичный адрес: <https://teassty.github.io/hollywood-car-detailing/>

## Примечания

- Цены не публикуются до получения актуального прайса.
- Данные формы не отправляются на сервер и остаются в браузере.
- Внешние фотографии не используются: исходники не удалось надёжно атрибутировать. Автомобильная графика создана специально для сайта в SVG.
- Шрифты Unbounded и Manrope подключены локально через Fontsource.
